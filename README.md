# RIVEN Portfolio — GitHub Pages Ready

This version is configured for the repository path `/riven-portfolio/`.

## Upload
Upload the **contents** of this folder to the repository root, then enable GitHub Pages from `main` / `(root)`.

## Why this build works
All local CSS, JS, favicon and project-page paths are relative, so GitHub Pages does not try to load them from the domain root.
